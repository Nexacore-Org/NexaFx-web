# NexaFx Glossary

Short definitions for domain terms used in the NexaFx product and codebase.

| Term                         | Meaning                                                                                                                                                  |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Swap / convert**           | Exchanging one supported currency or asset for another; the app uses “convert” for the user-facing flow and `swap` for the backend transaction endpoint. |
| **Custodial wallet**         | A wallet whose keys or asset access are managed by the service on behalf of the user.                                                                    |
| **Non-custodial wallet**     | A wallet where the user controls the secret key and the service does not hold signing authority.                                                         |
| **KYC / verification**       | Know Your Customer identity checks used to verify a user before eligible financial operations.                                                           |
| **OTP**                      | A one-time password sent during signup, login, or account recovery to confirm control of an account or contact method.                                   |
| **Withdrawal**               | Moving funds from a NexaFx wallet to an external destination address.                                                                                    |
| **Withdrawal limit**         | The maximum amount a user can withdraw for a currency or time period, based on account and compliance rules.                                             |
| **Deposit**                  | Adding funds to a NexaFx wallet from an external source.                                                                                                 |
| **Transaction**              | A recorded financial operation such as a deposit, withdrawal, or swap, with its amount, currency, status, and timestamps.                                |
| **Stellar**                  | The blockchain network used by NexaFx for supported wallet assets and payment operations.                                                                |
| **Custody / wallet address** | The public address used to receive or identify wallet funds; it can be shared, unlike a secret key.                                                      |
